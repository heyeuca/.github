# Who we are 🌿

euca started in 2025. We make software for people who'd rather open something and
find it already sorted out than spend an evening setting it up. A few apps later,
the way we work hasn't changed much: figure out what a product is really for,
leave out the rest, and hold that shape as it grows.

We're not trying to grow the catalog. A few things we can look after properly
feels better than a long list we can't.

# What we make

Small, native apps for Apple platforms. The choices are already made, so there is
very little to set up. New work goes deeper into what an app is already for rather
than wider, and nothing here is built to compete for your attention.

# What we leave out

- Options where a decision would do
- Features that try to cover every preference
- Updates that arrive without a reason

**If you need the broader tool, these are intentionally the wrong ones.**

# Contributing

[Tilde](https://github.com/heyeuca/Tilde) is MIT licensed, and both issues and
pull requests are welcome.

- **Bugs and rough edges** — always good to hear about
- **Fixes** — a pull request is the easiest way in
- **Ideas** — welcome, if they fit what an app is already for
